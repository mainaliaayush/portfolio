# Full-Stack Developer Portfolio (Django + React)

A full-stack web application built to learn and explore decoupling a Python/Django REST API backend from a modern React (Vite + TypeScript) single-page application.

## 🚀 Tech Stack

### Frontend
- **React 19** with **TypeScript**
- **Vite** (build tool and dev server)
- **Tailwind CSS v4** (utility-first styling)
- Hosted on **Cloudflare Pages**

### Backend
- **Python 3.12** & **Django 6**
- **Django REST Framework (DRF)** for RESTful endpoints (`/api/projects/`, `/api/contact/`)
- **django-cors-headers** & **WhiteNoise** for static assets
- **PostgreSQL** (production) / **SQLite** (local dev)
- Deployed on **Render** using **Gunicorn**

## 📦 Features
- Dynamic projects list served from Django database
- Interactive contact form with client validation and API persistence
- Django Admin interface to manage portfolio content
- Full CORS configuration and environment variable isolation (`.env`)

## 🛠️ Project Status
*Archived / Milestone Project*: Built as a hands-on learning project to master full-stack concepts, REST APIs, database migrations, and cloud deployments.
